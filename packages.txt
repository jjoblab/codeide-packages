# packages.txt
# ---------------------------------------------------------------------------
# CodeIDE APT repository — installable packages (aarch64 only).
#
# This file is read by `.github/workflows/build-packages.yml` to determine
# which `.deb` packages are built from source and published to the CodeIDE
# APT repository on GitHub Pages.
#
# Bootstrap packages (bash, apt, coreutils, ...) are NOT listed here —
# they are listed in `bootstrap-packages.txt` instead. Keeping the two
# lists separate makes the bootstrap minimal and avoids confusing the
# bootstrap builder with full-APT-repo packages.
#
# Packages listed here are installable from a running CodeIDE shell via:
#     pkg install <name>
#   or
#     apt install <name>
#
# IMPORTANT: This repository focuses on the minimal terminal runtime + Java.
# Android SDK, AAPT2, D8, R8, NDK will be added in a later phase.
#
# One package name per line. Comments start with `#`. Blank lines ignored.
# ---------------------------------------------------------------------------
